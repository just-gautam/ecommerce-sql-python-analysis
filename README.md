# 🛒 Brazilian E-Commerce (Olist) — SQL + Python Analysis

**Author:** Gautam Bhardwaj
**GitHub:** https://github.com/just-gautam

## 🛠 Tools Used
Python · SQLite · Pandas · Matplotlib · Seaborn

## 📂 Dataset
Olist Brazilian E-Commerce — Kaggle
Download: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
Place all CSV files inside the /data folder.

## 🔍 Business Questions Answered
1. How many orders, customers, revenue total?
2. Revenue by product category?
3. Monthly revenue over time?
4. Which payment methods are most used?
5. Review score distribution?
6. Which states order the most?
7. Top 10 sellers by revenue?

## 🚀 How to Run
pip install -r requirements.txt
Open Ecommerce_SQL_Analysis.ipynb in VS Code or Jupyter
